# love-telegram-bot
# 💞 Love Telegram Bot — романтическая игра для двоих

Бот задаёт вопросы для сближения пары.  
Содержит 100 вопросов, игра с уровнями, поддержка случайных вопросов.

## Установка

pip install -r requirements.txt

## Запуск

python love_bot.py

## Настройка токена

В файле love_bot.py замените:

token("YOUR_TOKEN_HERE")

на ваш токен от BotFather.

## Развёртывание на Render

1. Создать новый Web Service
2. Подключить GitHub репозиторий
3. Build command: (не нужен)
4. Start command:

python love_bot.py

5. Deploy
